# MeetPoint

**MeetPoint** es una aplicación web diseñada para optimizar la gestión y reserva de salas en espacios de coworking, ofreciendo una experiencia eficiente, intuitiva y dinámica para los usuarios.

## 🧩 Funcionalidades Principales

- **Reservas en tiempo real**: Consulta disponibilidad, selecciona sala, horario y duración (con límites definidos por el local).
- **Cancelaciones**: Permitidas con al menos 2h de antelación y motivo obligatorio. Los administradores pueden gestionar casos especiales.
- **Información de salas**: Capacidad, equipamiento, ubicación y precios dinámicos según recursos.
- **Sistema de reseñas**:
  - Puntuaciones de 1 a 5 estrellas.
  - Comentarios con nombre y fecha.
  - Filtros por puntuación o relevancia (según número de "me gusta").
  - Filtro de lenguaje inapropiado automático.
- **Panel de administración**:
  - Gestión de salas, reservas y usuarios.
  - Moderación de comentarios.
- **Interfaz responsive**: Optimizada para escritorio, móviles y tablets.

## ⚙️ Tecnologías Utilizadas

### Frontend
- **HTML, CSS, JavaScript**
- **Bootstrap** (diseño responsive)
- **Blade** (sistema de plantillas de Laravel)

### Backend
- **Laravel (PHP)**
- **MySQL** (base de datos relacional)

## 🧠 Características

- Gestión inteligente en tiempo real para optimizar el uso del espacio.
- Sistema de reseñas verificadas y filtrables.
- Modelo de precios dinámico basado en demanda y recursos.
- Moderación automática y manual para garantizar contenido apropiado.
